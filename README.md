# Mon enfance – L'imparfait

Interactive activities (imparfait) – *Learn French with Haresh Sir*. Open `index.html` (or enable GitHub Pages: Settings → Pages → `main` / root).

1. **Yanis** – gap-fill with word box (first person)
2. **Camille** – gap-fill with word box (third person)
3. **Mots mélangés** – nouns, verbs, adjectives, prepositions, adverb and pronoun removed; each gap is tagged with its word class
4. **J'écoute** – listening: hear each sentence (normal / slow speed, or the whole dialogue) and type the missing word; accent buttons; accent-less answers accepted for partial credit

Common features: name box, green ✓ / red ✗ feedback, points, streak, hints after two mistakes, score out of 20, stars, confetti, records saved per name in the browser.

Audio (`audio/`) was generated with the Kokoro French voice (ff_siwis). If a file cannot be played, the page falls back to the browser's French voice.
